# IoT Temperature Monitoring & Automation System

This project was developed as part of the DecodeLabs IoT Internship.

## Features
- Temperature monitoring using LM35 sensor
- LCD temperature display
- LED and buzzer automation alert
- Arduino UNO based system
- Proteus 9 circuit design

## Components Used
- Arduino UNO
- LM35 Sensor
- 16x2 LCD
- LED
- Buzzer
- Potentiometer

## Tools Used
- Arduino IDE
- Proteus 9
- MS Word
